# sui-move-defi-lending

Decentralized lending protocol implemented in Move on Sui.

## Overview
Starter for building lending/borrowing markets on Sui using its object-centric Move language.

## Tech Stack
- Move (Sui)
- @mysten/sui.js
- React frontend

## Getting Started
```bash
git clone https://github.com/Proxtox/sui-move-defi-lending.git
cd sui-move-defi-lending
sui move build
```

## Key Files
- `sources/lending.move` - Basic shared lending pool with deposit logic
